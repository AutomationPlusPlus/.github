# automation++ ¯\\\_(ツ)\_/¯

Automation with extra plusses.

We build tools that do the boring stuff so you don't have to: infrastructure
automation, config wrangling, and the occasional interface that absolutely did
not need to be that fancy.

**Why "++"?** Because plain automation wasn't enough, and `automation--` sends
the wrong message.

## 🔗 Links

- 🌐 [automation-plus-plus.com](https://automation-plus-plus.com): products,
  docs, and downloads. It also generates shrugs. We're very proud of it.
- 📦 Repos are listed below. Some are public, and some are still marinating.

## 🛠️ How we work

- **Open core.** Product cores are open source, and paid extras live in
  separate modules.
- **Self-hosted first.** Your config and your keys stay on your machines.
- **Agents write, humans review.** Coding agents do much of the typing. A
  human reviews every change, and the risky parts always.
- **Small, signed-off commits.** Conventional Commits, a DCO sign-off, and a
  green `make ci` before anything merges.
