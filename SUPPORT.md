# Getting support

## Questions and help

Ask questions in GitHub Discussions on the product's repository. Community
support is best effort.

Before you ask, check the product documentation on
[automation-plus-plus.com](https://automation-plus-plus.com).

## Bugs

Report bugs with the bug report form in the product repository's issues.
For operational problems, attach a support bundle. The product's support
bundle command creates one and redacts secrets. Read
[CONTRIBUTING.md](https://github.com/AutomationPlusPlus/.github/blob/main/CONTRIBUTING.md)
if you would like to send a fix.

## Feature requests

Use the feature request form in the product repository's issues.

## Security problems

Do not use issues or Discussions. Follow
[SECURITY.md](https://github.com/AutomationPlusPlus/.github/blob/main/SECURITY.md).
